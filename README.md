# Shokhrukh Ibragimov
**PhD Candidate in Mathematics of Machine Learning | Bochum, Germany**

I research the mathematical foundations of deep learning, focusing on optimization dynamics, loss landscapes, and neural network convergence. My repositories contain the code I use to run numerical simulations and support my theoretical results.

### Main Focus Areas
* **Optimization Dynamics:** Translating mathematical proofs into high-performance PyTorch simulations to study gradient descent.
* **Approximation Theory:** Proving the mathematical expressivity of neural networks, including how deep NNs overcome the curse of dimensionality in scenarios where shallow networks inherently fail.
* **LLM Evaluation:** Benchmarking Large Language Models on their capacity for first-order logic.
